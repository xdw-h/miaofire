# 喵火前线

原创猫咪放置射击网页试玩版 · 小队防线版 1.3。无第三方包、无账号、无网络资源依赖。

## 手机在线试玩

公开访问地址：**https://xdw-h.github.io/miaofire/**。

手机浏览器直接打开即可游玩，不需要安装或保持电脑开机。手机与电脑的存档分别保存在各自浏览器，不会自动同步；本地试玩的进度也不会迁移到此公开地址。

发布方式：GitHub Pages 从 `main` 分支的根目录部署。页面资源使用相对路径，支持 `/miaofire/` 子目录；`.nojekyll` 使网站作为普通静态文件发布。后续推送到 `main` 会自动更新网页。

## 开始试玩

1. Windows 下双击 `start.cmd`，保持服务窗口打开。
2. 在浏览器打开 **http://localhost:4173**。
3. 猫咪自动开火；点击“成长”升级，点击“武器”抽取并装备枪械。

也可以在此目录执行 `node server.mjs`。建议 Node.js 20 或更高版本；Windows 启动脚本优先使用本机 Codex 附带的 Node 运行时。无需安装依赖。

端口被占用时先检查游戏是否已经运行。可通过 `node server.mjs --port 4174` 使用另一个端口，但不同端口的存档相互独立。请固定使用 `localhost`；`127.0.0.1` 是另一份独立存档。

## 玩法

- 每关 60 秒，击败 10 个敌人后自动前进，普通关获得 10 钻石和 3 鱼干。
- 金币升级攻击力、射速、收益、生命与护盾。开局赠送 30 钻石，10 钻石抽取一把 C 级枪械。
- 最多三只猫出战；装备一把枪械就有一只猫。手枪、冲锋枪、霰弹枪等概率抽取。
- 两把同类型、同等级且未装备的武器合成为一把随机类型的高一级武器，最高 SS 级。
- 通过第 3 关后可转生。每通过 3 关得到 1 颗紫晶，每颗永久增加 10% 基础攻击力。转生保留枪械、装备、钻石、紫晶及全部伙伴养成，重置金币、金币升级和关卡。

## 伙伴与补给挑战

- 最高通关第 1、3、5 关后，可在「伙伴」邀请松果松鼠、疾风雀、招财狸。一次携带一位，分别增强攻击、射速、金币收益；使用鱼干可喂养至 20 级。
- 成长足迹按累计击碎数与最高通关数发放一次性鱼干奖励，转生不重置。老玩家可直接领取已经达成的奖励。
- 第 3 关后开放五档补给挑战：30 秒内击破训练木偶，逐档解锁，首通与重复通关奖励不同。没有门票或每日次数限制。
- 挑战期间主线暂停，装备和养成锁定；退出后继续原主线。未完成挑战退出或刷新没有奖励；已通关的鱼干即时保存，不会重复发放。
- 手枪点射、冲锋枪连发、霰弹枪扇形弹道具有不同后坐力和音色，附有命中闪白、碎片与金币飞入反馈。霰弹枪的散射是视觉表现，每次射击只结算一次伤害。系统开启减少动态效果时自动减弱动画。

## 森林敌人与 Boss

| 对手 | 出现条件 | 特点 |
|---|---|---|
| 苔团、蘑菇精 | 普通波次交替出现 | 沿用基础生命和金币曲线 |
| 松果甲虫 | 第 3 关起，每关第 4、8 波 | 护甲抵消 25% 伤害，整数伤害向下取整，最低 1；金币为 1.5 倍 |
| 古木守卫 | 第 5、10、15……关的最后一波 | 4 倍生命、5 倍金币；该关通关总奖励 20 钻石、10 鱼干 |

Boss 与前九波共用本关 60 秒倒计时。失败后可先升级或喂养再重试，已得到的资源保留，从本关第一波重新开始。未通关不发钻石与鱼干；击败 Boss 后显示奖励战报并继续自动冒险。转生后重新通关正常发奖。

旧版击碎树木数量继续计入成长足迹。材料挑战仍是独立的训练木偶，不受主线护甲/Boss 规则影响。

## 小队防线

- 小队共享 100 点生命、60 点护盾。古木守卫每 5 秒重击一次，最后 2 秒显示蓄力预警；第 5 关伤害 40，之后每个 Boss 关增加 8。普通敌人与训练木偶不会攻击。
- 护盾先吸收伤害，超出的部分扣除生命；连续 3 秒没有受击后，每秒恢复 8 点护盾。生命在本关中不自动恢复，耗尽即失败，已获得资源保留。
- 「生命强化」每级 +20 生命上限，「护盾强化」每级 +15 护盾上限，各最多 30 级。购买只补充新增容量；转生时与其他金币升级一起重置。
- 进入新关、重试、转生或刷新时恢复满状态；重试和刷新从当前关第一波重新开始。材料挑战冻结主线生命、护盾恢复及 Boss 蓄力，返回后继续。
- 仍然自动射击与防御，无需手动躲避。暂停、弹窗与切到后台都会冻结攻击计时；同一步先判超时，再结算小队射击，已被击败的 Boss 不会反击。

## 存档与使用范围

资源交易后及每 5 秒自动保存到此浏览器的本地存储。刷新后，养成资源保留，当前关卡从起点重新开始。后台和弹窗打开时暂停战斗；没有离线收益。声音默认关闭，点击场景右下角音量按钮可开启。

保存位置与浏览器、访问地址、端口绑定。清理网站数据、更换浏览器、使用隐私模式或更换访问地址可能看不到原进度。损坏的存档不会自动覆盖；界面会显示临时试玩提示，可在设置中确认重开。

1.3 首次读取版本 1/2 存档时，先将完整原文备份到 `miaofire.save.v1.backup-v1` 或 `miaofire.save.v1.backup-v2`，再把 `miaofire.save.v1` 升级为版本 3。原有资源、武器、装备、伙伴和历史进度保留，新增生命与护盾强化从 0 级开始。版本 1 尚无伙伴进度，因此从未领取状态开始。如果备份或写入失败，将保留原存档并关闭本次自动覆盖，页面会提示临时试玩。

本地启动脚本仅提供本机访问；手机请使用上方 GitHub Pages 公开链接。当前版本未接入账号同步、广告、付费和公开排行榜。

## 开发与检查

```sh
node --test tests/*.test.mjs
node --check src/app.mjs
node --check src/scene.mjs
node server.mjs
```

- `src/game.mjs`、`src/progression.mjs`：主线与挑战战斗、伙伴、鱼干及成长奖励。
- `src/enemies.mjs`、`src/enemy-art.mjs`：怪物与 Boss 规则、原创 Canvas 绘制。
- `src/survival.mjs`、`src/survival.css`：Boss 蓄力、血盾规则与防线界面。
- `src/storage.mjs`：带版本的存档校验与恢复。
- `src/scene.mjs`、`src/impact-timeline.mjs`：原创森林、战斗特效与目标命中队列。
- `src/app.mjs`、`src/progression-ui.mjs` 及对应 CSS：响应式界面、键盘操作与弹窗。
- `src/icons.mjs`：本地 SVG 图标与枪械卡片。

所有角色和场景均通过本地绘制生成，不使用参考游戏的素材。此为可验证玩法的单机试玩版，数值为自定配置。
