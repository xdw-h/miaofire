# 喵火前线

原创猫咪放置射击网页试玩版 · 无尽守卫版 1.9.0。游戏本体无第三方包，无需玩家注册；共享荣誉榜通过 Cloudflare Worker + D1 提供服务。

## 无尽守卫与生存榜

最高通关第 5 关后，在「挑战」进入无尽守卫。固定 B 级手枪、穿甲弩、狙击枪三猫，不带入主线装备、伙伴、紫晶和祝福；挑战期间主线冻结。

每波限时 60 秒，敌人生命逐波增强，每 5 波为 Boss。换波保留生命、护盾和技能冷却，击败 Boss 后暂停三选一：本局武器伤害 +25%、射速 +15%，或恢复 40% 生命上限与 60% 护盾上限。前两项按选择次数线性叠加。关闭补给弹窗不会继续战斗，可从战斗画面或挑战页重新打开。

防线耗尽或单波超时结算；也可主动结束。每完成一波立即保存最高记录，刷新会结束当前战局，最佳成绩保留。无尽守卫不发钻石和鱼干。结算后可手动填写昵称提交生存榜，所有玩家共享前 100 名；按最高完成波数排序，同波数按服务器首次达到时间排序。主线榜与生存榜在荣誉榜弹窗中切换，使用同一浏览器身份、独立战绩。

存档升级为版本 5；版本 1–4 按原版本原样备份后迁移，其中真实旧版 v4 会新增 `miaofire.save.v1.backup-v4`。原养成资源保留，无尽最佳从 0 波开始；转生保留无尽记录。备份失败则保留原始存档并提示临时试玩。

## 森林荣誉榜

顶部奖杯、战斗下方、主线失败结算和转生确认中均可打开荣誉榜。填写 1–16 字昵称，手动提交主线最佳通关数与下一关波次；前 100 名全体玩家可见，前三名显示奖牌，自己的排名单独显示。打开榜单暂停战斗，关闭后按原来的暂停状态继续。

按通关数、下一关波次降序，同分按服务器首次记录时间排序。同一浏览器身份仅保留最佳成绩，较差成绩可更新昵称但不降低战绩。未提交的最佳波次也保存在本地，刷新、重试、转生不丢失。游戏重开不删除荣誉记录。

清除网站数据或更换浏览器会产生新身份；昵称可以重名，本版不提供账号、跨设备找回或存档同步。只上传昵称和战绩，不上传游戏存档。服务端验证范围、限制频率并隔离玩家身份，但成绩来自客户端，属于休闲榜单，不用于奖金竞赛。

部署见 [荣誉榜服务说明](backend/honor/README.md)。`src/leaderboard-config.mjs` 为空时会提示尚未开放；不能把本地预览视为已上线的全网排行榜。

## 手机在线试玩

公开访问地址：[打开喵火前线](https://xdw-h.github.io/miaofire/)。

手机浏览器直接打开即可游玩，不需要安装或保持电脑开机。手机与电脑的存档分别保存在各自浏览器，不会自动同步；本地试玩的进度也不会迁移到此公开地址。

发布方式：GitHub Pages 从 `main` 分支的根目录部署。页面资源使用相对路径，支持 `/miaofire/` 子目录；`.nojekyll` 使网站作为普通静态文件发布。后续推送到 `main` 会自动更新网页。

## 开始试玩

1. Windows 下双击 `start.cmd`，保持服务窗口打开。
2. 在浏览器打开 **http://localhost:4173**。
3. 猫咪自动开火；点击“成长”升级，点击“武器”抽取并装备枪械。

也可以在此目录执行 `node server.mjs`。完整测试与本地荣誉榜需要 Node.js 22.13 或更高版本，建议 Node.js 24；Windows 启动脚本优先使用本机 Codex 附带的 Node 运行时。游戏本体无需安装依赖。

端口被占用时先检查游戏是否已经运行。可通过 `node server.mjs --port 4174` 使用另一个端口，但不同端口的存档相互独立。请固定使用 `localhost`；`127.0.0.1` 是另一份独立存档。

## 玩法

- 每关 60 秒，击败 10 个敌人后自动前进，普通关获得 10 钻石和 3 鱼干。
- 金币升级攻击力、射速、收益、生命与护盾。开局赠送 30 钻石，10 钻石抽取一把 C 级枪械。
- 最多三只猫出战；装备一把武器就有一只猫。七种武器等概率随机抽取，也可花 20 钻石定向领取指定 C 级武器。
- 两把同类型、同等级且未装备的武器合成为一把随机类型的高一级武器，最高 SS 级。
- 通过第 3 关后可转生。每通过 3 关得到 1 颗紫晶，每颗永久增加 10% 基础攻击力。转生保留枪械、装备、钻石、紫晶及全部伙伴养成，重置金币、金币升级和关卡。

## 伙伴与补给挑战

- 最高通关第 1、3、5 关后，可在「伙伴」邀请松果松鼠、疾风雀、招财狸。一次携带一位，分别增强攻击、射速、金币收益；使用鱼干可喂养至 20 级。
- 成长足迹按累计击碎数与最高通关数发放一次性鱼干奖励，转生不重置。老玩家可直接领取已经达成的奖励。
- 第 3 关后开放五档补给挑战：30 秒内击破训练木偶，逐档解锁，首通与重复通关奖励不同。没有门票或每日次数限制。
- 挑战期间主线暂停，装备和养成锁定；退出后继续原主线。未完成挑战退出或刷新没有奖励；已通关的鱼干即时保存，不会重复发放。
- 手枪点射、冲锋枪连发、霰弹枪扇形弹道具有不同后坐力和音色，附有命中闪白、碎片与金币飞入反馈。霰弹枪的散射是视觉表现，每次射击只结算一次伤害。系统开启减少动态效果时自动减弱动画。

## 森林军械库

在「武器 → 查看图鉴 / 定向补给」查看全部类型并领取指定武器。随机补给 10 钻石、定向补给 20 钻石，均得到 C 级；背包满、钻石不足或挑战中不能领取。合成仍需要两把同类型同等级的未装备武器，产物为随机类型的高一级武器。

| 武器 | C 级基础单发 / 每秒发数 | 特性与用途 |
|---|---|---|
| 松果手枪 | 5 / 2 | 稳定均衡点射 |
| 薄荷冲锋枪 | 3 / 3.6 | 高频射击，快速清理普通敌人 |
| 落日霰弹枪 | 12 / 0.95 | 重型散射，一次射击结算一次伤害 |
| 鹰眼狙击枪 | 18 / 0.5 | 对 Boss 伤害 +35%，低频重击 |
| 荆棘穿甲弩 | 9 / 1.05 | 无视护甲，克制松果甲虫 |
| 熔果火箭筒 | 24 / 0.38 | 射击前目标生命不高于 30% 时，伤害 +50% |
| 星萤护盾枪 | 4 / 1.6 | 每次开火为主线或每日试用小队补盾，火力较低 |

护盾枪每发补盾量按品质为 C/B/A/S/SS：2/3/5/7/10；不随攻击升级增长，不超过护盾上限，不恢复生命、不重置受击后的回盾等待，在材料挑战中不影响主线防线。其他伤害仍随品质、攻击升级和伙伴成长；条件增伤后按护甲规则向下取整。界面显示的「基础秒伤」不包含条件增伤和护甲影响。

新增长枪瞄准镜、弓臂、火箭筒口与护盾核心外形，分别使用曳光、弩箭、尾焰火箭和青色光弹。命中显示猎王/收割增伤标记，补盾时在猫咪旁显示实际恢复量。旧武器、装备及养成可继续使用。

## 森林敌人与 Boss

| 对手 | 出现条件 | 特点 |
|---|---|---|
| 苔团、蘑菇精 | 普通波次交替出现 | 沿用基础生命和金币曲线 |
| 松果甲虫 | 第 3 关起，每关第 4、8 波 | 护甲抵消 25% 伤害，整数伤害向下取整，最低 1；金币为 1.5 倍 |
| 古木守卫 | 第 5、10、15……关的最后一波 | 4.5 倍生命（四舍五入）、5 倍金币；该关通关总奖励 20 钻石、10 鱼干 |

Boss 与前九波共用本关 60 秒倒计时。失败后可先升级或喂养再重试，已得到的资源保留，从本关第一波重新开始。未通关不发钻石与鱼干；击败 Boss 后显示奖励战报并继续自动冒险。转生后重新通关正常发奖。

旧版击碎树木数量继续计入成长足迹。材料挑战仍是独立的训练木偶，不受主线护甲/Boss 规则影响。

## 小队防线

- 小队共享 100 点生命、60 点护盾。普通敌人登场 1 秒首击，最后 1 秒预警；后续攻击间隔第 1–2 关为 4 秒、第 3–7 关为 3.5 秒、第 8 关起为 3 秒。前两关普通伤害为 4，第 3 关起为 `6 + floor((关卡 - 3) × 0.9)`，甲虫额外 +6。换怪重新计时，提前击败可阻止反击。
- 古木守卫登场 3 秒首击，之后每 5 秒重击，最后 2 秒蓄力预警；第 5 关伤害 40，之后每个 Boss 关增加 8。生命不高于 50% 时狂暴，伤害增加 40% 并向上取整，攻击期限不突然提前。训练木偶不会攻击。
- 护盾先吸收伤害，超出的部分扣除生命；连续 3 秒没有受击后开始恢复，第 1–2 关每秒 8 点，第 3 关起每秒 4 点。生命在本关中不自动恢复，耗尽即失败，已获得资源保留。
- 「生命强化」每级 +20 生命上限，「护盾强化」每级 +15 护盾上限，各最多 30 级。购买只补充新增容量；转生时与其他金币升级一起重置。
- 进入新关、重试、转生或刷新时恢复满状态；重试和刷新从当前关第一波重新开始。材料挑战冻结主线生命、护盾恢复及 Boss 蓄力，返回后继续。
- 仍然自动射击与防御，无需手动躲避。暂停、弹窗与切到后台都会冻结攻击计时；同一步先判超时，再结算小队射击，已被击败的 Boss 不会反击。

## 攻击表现

苔团挤压后吐出黏液，蘑菇精抖动伞盖释放孢子，松果甲虫投出旋转松果，古木守卫挥臂让根刺沿地面推进。各自拥有不同轨迹、尾迹与命中碎片。

飞行位于蓄力预警的末段，到达小队时结算伤害并亮起护盾接触处；数字浮在小队旁。提前击败敌人会取消攻击；暂停冻结飞行，减少动态效果模式改用静态攻击符号。飞行与当前攻击期限保持一致，Boss 狂暴后眼睛变为橙色，并显示伤害增幅。

## 难度递进

第 1–2 关为练习，第 3–7 关为进阶，第 8 关起为险境。第 3 关起，敌人基础生命在原曲线上每关额外增加 4%，上限 35%。关卡数值固定，不根据玩家战力动态调整。中期需要投入生命与护盾，后期需要合成高阶武器并搭配养成；具体公式与模拟配置见 [难度调优记录](难度调优记录.md)。

## 远征祝福、联动与精英

- 每通过 3 关，主线暂停并提供三个不同祝福。关闭弹窗后可从「远征祝福」重新打开；刷新不会更换选项。祝福同类线性叠加，重试保留，转生清空，仅主线生效。
- 六种祝福：攻击 +8%、射速 +5%、击杀回盾 +6、生命不高于 35% 时伤害 +20%、护盾上限 +15（补齐新增容量）、Boss 伤害 +12%。不同条件乘算，最后按护甲取整。
- 同时装备穿甲弩＋狙击枪：弩标记目标 4 秒，狙击对标记增伤 30%。护盾枪＋火箭筒：护盾枪每发积累一层，最多三层；火箭消耗全部蓄能，每层伤害 +10%。手枪＋冲锋枪：这两类武器射速 +8%。主线和挑战都可触发，但临时状态独立。
- 换敌清除标记、保留蓄能；换关、重试、换装备清空两者。场景下方显示当前联动及标记/蓄能，点击可查规则。
- 第 4 关起第 3、6 波是精英，生命 ×1.15、金币 ×1.8。再生：每 2 秒恢复 8% 最大生命；狂暴：伤害 +30%、后续攻击间隔 ×0.8，首次反击仍为 1 秒；护盾：额外 25% 最大生命护盾，伤害先扣盾。分别有绿、橙、蓝色光环和文字特性，Boss 不叠加精英。

## 主动技能与每日挑战

防线下方可点击三种技能。紧急护盾恢复 50% 护盾上限，冷却 18 秒；集火爆发使伤害 +60%，持续 5 秒，冷却 22 秒；急救鱼干恢复 25% 生命上限，冷却 25 秒，不消耗鱼干。满血/满盾不会浪费恢复技能；暂停、弹窗和后台冻结技能计时。换关保留冷却，重试/刷新重置；木偶挑战仅可使用爆发。

第 3 关后在「挑战」页进入每日挑战，三条规则依本机日期轮换：双猫突围、断补给防线、巨木连战。均为 60 秒，使用固定 B 级试用武器与属性，不带入主线养成、伙伴或祝福。双猫使用穿甲弩＋狙击枪；断补给使用手枪＋冲锋枪＋护盾枪，自动及武器回盾关闭，主动补盾可用；巨木连战使用弩＋狙击＋护盾枪，连续击败三个 Boss，中途不恢复生命护盾。其余两种击败十波，包含精英与最终 Boss。

每日首胜立即获得 20 钻石、40 鱼干，重复通关仅练习。失败、退出或刷新未完局不奖励。跨午夜按开战日期结算；页面卡片跨日自动更新。保存最近领奖日期，较早或相同日期不能再次领奖；转生保留。日期来自本机，每日挑战没有服务器校时或独立排行榜，荣誉榜统计主线成绩。挑战结束返回时主线战斗与技能冷却继续之前的状态。

## 存档与使用范围

资源交易后及每 5 秒自动保存到此浏览器的本地存储。刷新后，养成资源保留，当前关卡从起点重新开始。后台和弹窗打开时暂停战斗；没有离线收益。

声音默认关闭。点击场景音量按钮或「设置 → 开启声音」，启动成功后播放原创森林旋律与战斗音效。设置可调节 0–100% 音量，并点击「播放试听音」听三声提示音。音乐在设置弹窗和手动暂停期间继续，切到后台时停止；如果手机系统中断音频，切回后点击「重新开启声音」。刷新后需再次手动开启。音频启动失败或超过 4 秒无响应时会显示失败提示，不会误报已开启。没有声音时检查手机媒体音量、静音模式和蓝牙输出。

浏览器播放需要用户交互，并应检查音频是否真正进入运行状态；实现参考 [Chrome 音频自动播放说明](https://developer.chrome.com/blog/autoplay/#web-audio)。

保存位置与浏览器、访问地址、端口绑定。清理网站数据、更换浏览器、使用隐私模式或更换访问地址可能看不到原进度。损坏的存档不会自动覆盖；界面会显示临时试玩提示，可在设置中确认重开。

当前使用版本 5 存档，兼容版本 1/2/3/4。升级前先按原始版本，将完整原文备份到 `miaofire.save.v1.backup-v1`、`.backup-v2`、`.backup-v3` 或 `.backup-v4`，再写入新档。原有养成与资源保留；已通过第 3 关的版本 1/2/3 旧档获得最近一个三关里程碑的补领祝福。版本 1 补齐伙伴默认值，版本 1/2 的生命与护盾强化从 0 级开始。备份或写入失败时保留原档并关闭自动覆盖。刷新重置当前关的战斗、技能冷却和联动临时状态，保留祝福、待选选项、每日奖励及无尽最佳记录；未完成挑战退出且不发奖。

本地启动脚本仅提供本机访问；手机请使用上方 GitHub Pages 公开链接。当前版本已接入共享荣誉榜，未接入账号同步、广告和付费。

## 开发与检查

```sh
node --test tests/*.test.mjs
node --check src/app.mjs
node --check src/scene.mjs
node server.mjs
```

- `src/game.mjs`、`src/progression.mjs`：主线与挑战战斗、伙伴、鱼干及成长奖励。
- `src/weapons.mjs`、`src/arsenal-ui.mjs`、`src/weapon-art.mjs`：武器规则、图鉴与定向补给、枪身及弹道。
- `src/audio.mjs`：用户点击启动、背景旋律、音效、音量及中断恢复状态。
- `src/enemies.mjs`、`src/enemy-art.mjs`：怪物与 Boss 规则、原创 Canvas 绘制。
- `src/survival.mjs`、`src/survival.css`：Boss 蓄力、血盾规则与防线界面。
- `src/enemy-attack-art.mjs`：分敌人攻击轨迹、飞行和接触反馈。
- `src/storage.mjs`：带版本的存档校验与恢复。
- `src/scene.mjs`、`src/impact-timeline.mjs`：原创森林、战斗特效与目标命中队列。
- `src/app.mjs`、`src/progression-ui.mjs` 及对应 CSS：响应式界面、键盘操作与弹窗。
- `src/icons.mjs`：本地 SVG 图标与枪械卡片。

所有角色和场景均通过本地绘制生成，不使用参考游戏的素材。此为可验证玩法的单机试玩版，数值为自定配置。
