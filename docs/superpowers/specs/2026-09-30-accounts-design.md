# 账号、云存档与游客绑定

用户已确认用户名密码、云存档、游客绑定并授权上线。保持游客直接游玩，不强制注册。账号服务独立监听回环地址，由现有 HTTPS Nginx 转发 `/api/account/`，不修改其他应用后端。采用 Node.js 22.13+ 内置 SQLite，独立数据库、专用系统用户、systemd 自动启动。

用户名为 3–24 位英文字母数字下划线，大小写不敏感；密码 10–128 字符，不自动 trim。使用随机盐 scrypt，随机会话仅保存摘要，Cookie Secure/HttpOnly/SameSite=Strict，30 天到期；所有写请求校验 Origin，登录注册找回按 IP 限流。提供一次展示的恢复码，找回时更换密码并撤销全部会话。

游客、本地账号保存空间隔离。登录后先展示本地与云端关卡、资源、更新时间；明确选择使用云端或上传本地，不自动合并资源。首次注册可绑定当前游客进度，保留游客原始副本。退出回到游客空间。密码与恢复码不得进入 localStorage、日志、Git。

云端只接受现有 version 6 合法存档，最大 256 KiB。每 30 秒上传，保存前先本地持久化。服务端 revision 乐观锁，冲突返回 409 并停止自动同步，用户重新选择后才能继续。网络失败保留本地进度，下次同步重试；账号身份改变或会话失效时停止同步。云存档不证明战绩真实，排行榜仍为休闲客户端战绩。

恢复云存档前备份目标本地进度，校验成功再切换；页面重载从当前关起点恢复，不保存战斗中间态。注册/登录不删除游客数据。账号共享稳定榜单标识，游客最佳记录可在选择本地存档时携带，保留原榜单记录。

验证覆盖密码哈希/找回/会话过期、跨账号隔离、Origin/限流、非法存档、并发覆盖、游客退出恢复、断网保存与界面端到端操作。Git 只保存代码和运维说明。
