# 账号与云存档实施计划

**Goal:** 在现有 HTTPS 游戏上交付用户名密码、云存档与游客绑定。

**Architecture:** 独立 Node HTTP + SQLite 账号服务，原生模块账号面板，按账号隔离浏览器存档；云端版本号阻止覆盖。

**Tech Stack:** Node.js 内置 crypto/sqlite/http、Nginx、systemd。

1. 先在 `tests/accounts.test.mjs` 写真实 HTTP 和 SQLite 测试，覆盖注册、登录、找回、Cookie、Origin、账户隔离、版本冲突；运行失败后实现 `backend/accounts/service.mjs`。
2. 在 `tests/account-client.test.mjs` 写存储隔离和存档选择测试，失败后实现 `src/account-client.mjs`。测试命令为 `node --test tests/account*.test.mjs`。
3. 创建 `src/account-ui.mjs`，在 app 初始化前恢复账号命名空间，增加账号入口，弹窗暂停战斗；安全替换本地进度后重载。
4. 修复相对排行榜 API 地址，运行 `node --test tests/*.test.mjs`，浏览器验证注册绑定、刷新、退出和多账号隔离。
5. 独立部署到 `/opt/miaofire-accounts`，数据库 `/var/lib/miaofire-accounts/accounts.sqlite`，回环端口 4186；备份并增量添加 Nginx 路由。验证 HTTPS 后提交代码和交接文档，不提交凭据。
